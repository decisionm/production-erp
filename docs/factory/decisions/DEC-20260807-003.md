The paper report's 'CT' column is the cycle time DIALED IN for that particular run — an observation of the run, not a standard. The same product carries a different CT nearly every shift across the photographed reports (100 RC 11.0 / 10.92 / 11.6; 200 RA 14.5 / 15.0 / 15.4 / 17.6; 450 Rib 19.3 / 19.98 / 19.4). Consequence: a paper-CT vs master-CT difference is NOT a norm error, and efficiency comparisons must treat the paper CT as the run's observed setting — the ERP's standard CT snapshotted at batch start remains the yardstick. Resolves PENDING Q20 and reframes the cycle-time rows of Q18 as observations, not disagreements.
