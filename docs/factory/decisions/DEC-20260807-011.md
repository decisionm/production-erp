A shift voucher is offered to the Tally agent only when BOTH conditions hold: (a) its shift's end time has passed for its production date — derived from shifts.end_time, NEVER hardcoded clock times (the factory's 7am/3pm/11pm are today's shift ends, not constants); an overnight shift's voucher for production date D releases at D+1's end time — AND (b) an idle-hold has elapsed: at least N minutes since the voucher's last merge/rebuild, N configurable with default 15. A voucher created after its shift already ended obeys only the idle-hold. The accountant keeps a manual 'Release now' override in the ERP, persisted and audited. The tray's 'Sync Now' stays exactly as-is.
