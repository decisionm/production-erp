A Store Issue's claim on material lasts as long as returnable quantity remains on it, whatever its status: OPEN, PARTIALLY RETURNED and COMPLETED issues alike. Completing a Store Issue moves no stock, so a completed issue with quantity still outstanding is still holding material on the floor and its return must still name it. Anything keyed on StoreIssueStatus::isOpen (Issued|PartiallyReturned) treats a completed issue as finished and is wrong for this purpose — the UI gate on the handover return door was keyed that way and has been changed to what is outstanding.
