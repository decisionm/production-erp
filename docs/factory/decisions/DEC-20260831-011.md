Every arrival waits for incoming QA before the store may issue it. This required no new gate: a bag born on a goods receipt is already created waiting_qc, and DEC-20260825-001 already forbids held material leaving a store by any door. It had simply never fired, because no arrival ever created a bag. Making the lots block mandatory on weighed arrivals is what switches it on, so the two answers are one behaviour: receive, hold, inspect, release. Counted materials create no bags and so are not held — which follows from the limit recorded alongside the lot-capture decision, not from a separate ruling about QA.
