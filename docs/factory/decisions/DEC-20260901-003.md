A DAMAGED RETURN NEVER GOES BACK TO USABLE STOCK. When unused raw material, packing material or a consumable comes back from Production, a GOOD return goes to the Store as usable stock exactly as before, and a DAMAGED return goes to QUALITY INSPECTION instead - it is never added to the Store's issuable balance on the way. Only after Quality has CONFIRMED the damage does the quantity move to Scrap. This resolves the narrowed PENDING Q89 and supersedes the recording-only boundary the return door shipped with, under which a damaged return moved exactly what a good one moved. HOW THE GUARANTEE IS MADE, because the mechanism is part of the rule: quality hold is an INTERNAL LOCATION of the one operational Store (DEC-20260830-002), a warehouse row exactly as Production/WIP is, so held material is out of the Store's issuable balance BY CONSTRUCTION rather than by a filter a later screen could forget - stock balances and every stock read are per item AND warehouse. Where no quality-hold location can be resolved the damaged return is REFUSED with a message naming the settings fix; it never falls back to the Store. No warehouse row is created by this decision: naming the location is a deliberate master-data act by a person. SCRAP IS AN ISSUE OUT OF STOCK, not a change of item identity - the same route incoming QC already uses for material it rejects (its Rejections Out issue) - because this ERP has no scrap-item mapping for a purchased input and DEC-20260901-002 expressly leaves which Scrap item undecided; nothing here invents or creates a Tally master. A damaged return still CLOSES its store issue's own quantity: the material did leave production, and the handover's arithmetic is about the floor, not about whether the material is usable. TWO THINGS ARE EXPRESSLY NOT DECIDED. (1) What Tally should receive when returned material is scrapped - the sibling clause DEC-20260825-001 already leaves open for QA rejection at arrival - and no voucher is posted or staged. (2) The RELEASE path, where Quality inspects and does NOT confirm damage, is built and is the agent's reading of the word 'directly' in 'a damaged return must never go directly back to usable stock': without it a mis-ticked line would strand good material permanently, which is the failure the return door exists to prevent. If that reading is wrong, say so and it is withdrawn.
