ONLY PET RESIN GOES INTO THE COMMON DAY BIN; MASTERBATCH IS NOT A BIN MATERIAL. Masterbatch does not go into the common PET day bin: it is loaded or dosed separately for the production machine or run. No other material is tipped into the bin either; packing material and every other input stays in its bag, box or roll on the floor. PET resin is a bin material, so under DEC-20260902-003 it is never returned to the Store once issued. Masterbatch is material on the production floor: once it has been poured, loaded, mixed or dosed into the machine's production system it cannot be returned to the Store; only unused masterbatch that is still physically identifiable in its container can be returned, at the end of the day, as DEC-20260831-005 and DEC-20260901-001 provide for non-bin materials. Masterbatch's actual consumption remains recorded against the production batch (DEC-20260806-003 unchanged). THE BIN-MATERIAL FLAG IS SET PER ITEM BY AN AUTHORISED PERSON, as a master-data act. The Tally stock group that DEC-20260827-001 reads may only PROPOSE the flag; it must never set it automatically, because a stock group classifies an item and does not prove its physical feed path. An item nobody has flagged is NOT a bin material. Resolves Q94(c) and closes the masterbatch point DEC-20260902-003 left open.
