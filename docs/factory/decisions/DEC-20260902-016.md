THERE IS NO SEPARATE STORE-ACCEPTANCE STAGE FOR FINISHED GOODS. Complete Batch records the finished goods in the Store's finished-goods location, as it does today. Quality then performs the checklist and records the final OK and rejected quantities (DEC-20260902-006), followed by the Plant Manager and Accounts approvals (FC-05, DEC-20260902-010). The Store does not sign the same receipt again. The Store's dashboard must show, for finished goods, the completed, Quality-pending, approved and rejected quantities, each opening the rows behind the figure. If Quality finds a count difference, it returns the batch to Production for correction through the existing return-to-production action; that is the correction path, not a Store count. A separate Store acceptance may be introduced later ONLY if the factory identifies a real physical handover problem, and that would be a new decision. Together with DEC-20260901-005 this resolves Q78 in full.
