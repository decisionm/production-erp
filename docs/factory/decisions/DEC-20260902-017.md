THE START BATCH READINESS GATE IS ENFORCED, AFTER EVERY ACTIVE PRODUCTION PRODUCT SHOWS READY. Start Batch must REFUSE when an active production product is missing any of: unit of measure, standard weight, cycle time, cavities, packing count, Tally item, Tally godown, or an active machine configuration. The refusal must clearly name every missing field. Colour remains a WARNING, never a refusal, because a clear product requires no masterbatch (FC-07). ROLLOUT ORDER, which is part of the rule: enforcement is NOT enabled immediately. First the standards readiness workspace is run against LIVE data and every active production product is corrected using verified values entered by an authorised person; a missing value is never invented and never filled automatically. After every active production product the factory requires shows Ready, the enforced gate is switched on (production.readiness.enforced). Inactive, archived or unused products must not delay that activation. Until the switch is thrown the gate stays watch-only exactly as shipped, with every gap named as a warning. The precedence a run reads its figures from is unchanged: configuration, then standard, then item master (DEC-20260805-005).
