A PRODUCT STANDARD KEEPS AT MOST ONE OPTIONAL DEFAULT PACKAGING; A FORCED DEFAULT IS NEVER REQUIRED. At Start Batch the packaging is resolved as follows: if the product has only one valid packaging option it is selected automatically; if it has several and one is marked default, the default is used; if it has several and no default, the supervisor is asked 'How is it packed?' at Start Batch and chooses. The selected packaging is saved in the batch's snapshot (DEC-20260805-005), so a later change to Product Configuration never alters an existing batch. A product that regularly ships in two packing methods does not need a forced default; the supervisor selects the correct one when starting the batch. This resolves Q45 as a confirmation of the shipped 'at most one default' rule, with the three resolution cases stated. Packaging identity rules are unchanged (DEC-20260810-003, DEC-20260821-001).
