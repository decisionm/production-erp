ANY USER WITH THE PROCUREMENT WRITE PERMISSION MAY APPROVE A PURCHASE REQUISITION, EXCEPT THE PERSON WHO RAISED IT. Self-approval is REFUSED with a clear message. The system records the requester, the approver and the approval time on the requisition. Administrator status must not silently bypass this rule: there is no Administrator exemption, exactly as the batch approval chain has none (FC-05). The Store may raise a requisition, but the same Store user cannot approve their own requisition. No new role or permission is created by this decision; if the factory later wants approval restricted to a particular role, that is introduced through a separate decision. Rejection follows the same four-eyes comparison as approval.
