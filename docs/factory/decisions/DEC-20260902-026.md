VENDORS CARRY ONE OR MORE OF FIVE CLASSIFICATIONS, SET BY A PERSON, AND CLASSIFICATION CONTROLS THE DEFAULT VIEW ONLY. The five classifications are: Resin; Packaging; Consumables, Spares and Tooling; Service; Other. A vendor may have one or more of them, set by an authorised person holding the procurement write permission. The Tally ledger group may PROPOSE classifications but must never set them automatically. The Vendors tab and the purchase-order vendor picker show Resin, Packaging, and Consumables, Spares and Tooling by default; Service, Other and Unclassified vendors remain available through an explicit filter. Classification controls the default view only: it must not silently block an existing vendor from being selected on any document. Existing vendors remain UNCLASSIFIED until a person reviews them; nothing classifies a vendor on a guess. FC-06 is unchanged: classification carries no rate and no supplier detail beyond what the Vendors page already shows to procurement.
