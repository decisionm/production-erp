PENDING PRODUCTION REQUESTS ARE ORDERED BY THE SALES LINE'S PROMISED DATE, EARLIEST FIRST; THIS IS A QUEUE SORT ORDER AND NOT A PRIORITY RULE. Requests without a promised date come after dated ones; equal dates are ordered by the time the request was raised. Production may manually move a request and must record a reason; that manual position remains until Production removes it, and automatic re-sorting never silently undoes it. Started or completed jobs are never reordered. The promised date controls ONLY the default order of pending production work: it does not create customer priority, does not move any stock hold and does not change any reservation, so DEC-20260902-028, DEC-20260902-029 and DEC-20260902-030 stand unchanged and are not in tension with this rule. A re-sort is never silent: the queue shows each request's promised date, and when a sales desk changes a promised date and that moves a request without a manual position, the ERP clearly flags the request as moved since Production last looked. Resolves Q62(d).
