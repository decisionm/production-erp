PLANNING QUOTES ONE PRODUCTION LINE PER PRODUCT, AND THE QUOTED DATE IS A CEILING. The planning calculation stays at one machine per queued product. The displayed completion date is labelled as a ceiling in a few words (for example 'ceiling, 1 machine'), never with a paragraph, following the standing rule that floor users do not read page text; the assumptions behind the date - quantity, cycle time, cavities and available shift hours - are shown beside it as figures. No parallel-machine count is recorded or guessed, for any product. A future capacity-planning change may use verified machine compatibility, machine availability and the actual production schedule; a product-level number alone must never be used to promise an earlier date. Together with DEC-20260902-028 to DEC-20260902-032 this resolves Q62 in full.
