WHEN THE STORE CANNOT FULFIL A QUANTITY IT RECORDS WHY; IT MAY SEND ONLY THE SHORTFALL TO PRODUCTION; IF IT DOES NOT, THE LINE RETURNS TO SALES FOR ACTION; NOTHING IS RAISED AUTOMATICALLY. The Store records the reason it cannot fulfil the quantity. The Store may send only the shortfall to the production request queue (DEC-20260902-032 unchanged). If the Store does not send it, the shortfall returns to Sales for action. A production request is never raised automatically without the Store's own action. Resolves Q73.
